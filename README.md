# gemagick-site

Public site for **Gemagick**, an Android puzzle game.

Served by GitHub Pages from the `main` branch root:

| Page | URL |
|---|---|
| Landing | https://ifiszer.github.io/gemagick-site/ |
| Privacy policy | https://ifiszer.github.io/gemagick-site/privacy.html |

The privacy policy URL is referenced from the Google Play listing and must stay
reachable at that address for as long as the app is published. Don't rename
`privacy.html` or move the repo without updating Play Console first.

When ads or in-app purchases ship, update `privacy.html` before that version is released.

This repo holds only the public site. Application source lives elsewhere.
